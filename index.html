mail-cleanup

mail-cleanup 是 hoyushen 自用的個人信箱整理工具，在本人電腦上執行，透過 Gmail API 整理本人自己的 Gmail 信箱： 依寄件者加上標籤、建立篩選器、把過期通知與促銷信移到垃圾桶。

mail-cleanup is a personal mailbox-organizing tool used only by its owner (hoyushen). It runs locally and uses the Gmail API to label, filter and clean up the owner's own Gmail account. It is not offered to other users.
