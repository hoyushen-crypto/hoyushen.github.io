mail-cleanup 隱私權政策 / Privacy Policy

最後更新 / Last updated: 2026-10-12

適用範圍 / Scope

mail-cleanup 只供擁有者 hoyushen 本人使用，只存取本人授權的 Gmail 帳號，不對外提供服務。

mail-cleanup is used solely by its owner (hoyushen) and only accesses the owner's own Gmail account.

存取的資料 / Data accessed

透過 Gmail API（gmail.modify、gmail.settings.basic）讀取信件標頭與內容、管理標籤與篩選器、把信件移到垃圾桶。

Through the Gmail API (gmail.modify, gmail.settings.basic) the tool reads message headers and content, manages labels and filters, and moves messages to Trash.

資料使用與保存 / Use and storage

資料只在擁有者本人的電腦上處理，用於整理本人信箱；處理紀錄只存在本人電腦。不會傳送、出售或分享給任何第三方，也不用於廣告。

Data is processed only on the owner's own computer to organize the owner's mailbox. Logs stay on that computer. No data is sent, sold or shared with any third party, and none is used for advertising.

Google API 使用聲明 / Google API Limited Use

mail-cleanup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

撤銷授權 / Revoking access

可隨時在 Google 帳戶 → 第三方存取權 撤銷授權。

Access can be revoked at any time at Google Account → Third-party access.
